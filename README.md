# Smart Lost & Found

A PHP/MySQL web application for managing lost and found items in a college environment.

## Features
- Student, staff, and admin login
- Report lost and found items
- Search and browse items
- Automatic matching between lost and found entries
- Notifications and feedback
- Admin dashboard for managing users, items, matches, and activity logs

## Tech Stack
- PHP
- MySQL
- Bootstrap
- HTML/CSS/JavaScript

## Setup
1. Place the project in your local web server directory (for example, XAMPP htdocs).
2. Create a MySQL database named `smart_lostfound`.
3. Import the SQL files from the `database` folder.
4. Update database credentials in `config.php` if needed.
5. Open the project in your browser.

## Notes
- The project uses the default XAMPP/MySQL credentials in `config.php`.
- If you are deploying to a real server, update credentials before publishing.
